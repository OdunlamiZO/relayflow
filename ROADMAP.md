# Roadmap

Planned work that isn't built yet. Contributions are welcome. Open an issue first to agree on the
approach (see [`CONTRIBUTING.md`](CONTRIBUTING.md)).

## Channels

- Live-test the WhatsApp adapter against a real WhatsApp Business account: connecting, the
  webhook, inbound and outbound messages, and Ask Question buttons.
- Instagram adapter.

## Testing

- Frontend component tests for inbox states and the message composer.
- Playwright end-to-end tests, run in CI only (not in the pre-commit hook).

## Observability

- Sentry error reporting for the API and web app.
